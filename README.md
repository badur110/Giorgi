# ცხრამეტი ნაოჭი POS / Nineteen Pleats POS

მარტივი რესტორნის POS სისტემა პატარა ობიექტისთვის.

## მოთხოვნები

- 10 მაგიდა
- 1 ბარმენი/მოლარე
- 2 LAN თერმული პრინტერი
  - სალაროს პრინტერი
  - სამზარეულოს პრინტერი
- შეკვეთის გაგზავნისას იბეჭდება მხოლოდ ახალი დამატებული პროდუქტები
- სამზარეულოს ჩეკზე ფასები არ ჩანს
- საბოლოო ანგარიში იბეჭდება მხოლოდ სალაროს პრინტერზე
- გადახდის ტიპები: ნაღდი, ბარათი, შერეული
- პროდუქტის გაუქმება ხდება პაროლით
- პროდუქტების ხელით დამატება/რედაქტირება/გათიშვა
- სტანდარტული დღიური/თვიური რეპორტები

## ტექნოლოგია

ეს პირველი MVP ვერსია არის მარტივი PHP + MySQL აპლიკაცია, რომ პატარა რესტორნისთვის სწრაფად დაიდგას Windows ლეპტოპზე ან ჩვეულებრივ PHP ჰოსტინგზე.

პრინტერებზე პირდაპირი ბეჭდვისთვის საუკეთესოა ლოკალურად გაშვება იმავე ქსელში, სადაც პრინტერებია.

## დაყენება

1. დააყენე XAMPP ან Laragon.
2. შექმენი MySQL ბაზა, მაგალითად: `nineteen_pleats`.
3. გაუშვი `database/schema.sql`.
4. დააკოპირე `.env.example` როგორც `.env` და შეავსე მონაცემები.
5. გახსენი `public/index.php` ბრაუზერში.

## პრინტერის პარამეტრები

`.env` ფაილში:

```env
CASHIER_PRINTER_IP=192.168.1.50
KITCHEN_PRINTER_IP=192.168.1.51
PRINTER_PORT=9100
```

პრინტერები უნდა იყოს 80mm LAN/Ethernet ESC/POS მხარდაჭერით.

## უსაფრთხოება

`.env` ფაილი არ უნდა აიტვირთოს GitHub-ზე. გამოიყენე მხოლოდ `.env.example`.
