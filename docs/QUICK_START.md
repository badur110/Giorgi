# სწრაფი გაშვება და ტესტირება

GitHub-იდან პროგრამა პირდაპირ არ გაეშვება, რადგან ეს არის PHP + MySQL აპლიკაცია. საჭიროა ლოკალური სერვერი: XAMPP ან Laragon.

## XAMPP-ით გაშვება

1. დააყენე XAMPP.
2. ჩართე XAMPP Control Panel.
3. დააჭირე Start:
   - Apache
   - MySQL
4. GitHub-იდან გადმოწერე პროექტი ZIP-ით ან clone-ით.
5. პროექტი ჩადე ამ საქაღალდეში:

```text
C:\xampp\htdocs\nineteen-pleats
```

6. გახსენი phpMyAdmin:

```text
http://localhost/phpmyadmin
```

7. შექმენი ბაზა:

```text
nineteen_pleats
```

8. Import-ში გაუშვი:

```text
database/schema.sql
```

9. `.env.example` დააკოპირე და დაარქვი `.env`.

10. ბრაუზერში გახსენი:

```text
http://localhost/nineteen-pleats/public/
```

## რა უნდა დატესტო პირველ რიგში

1. შედი Admin-ით.
2. შედი პროდუქტებში.
3. დაამატე ახალი პროდუქტი.
4. გადადი მაგიდებზე.
5. აირჩიე მაგიდა 1.
6. დაამატე „ქალაქური ხინკალი“ ან შენ მიერ დამატებული პროდუქტი.
7. დააჭირე „შეკვეთის დაბეჭდვა“.
8. რადგან PRINTING_ENABLED=false არის, რეალურად არ დაიბეჭდება, მაგრამ შეკვეთა დაბეჭდილად მოინიშნება.
9. დაამატე კიდევ პროდუქტი და ხელახლა დააჭირე დაბეჭდვას — უნდა დაბეჭდოს მხოლოდ ახალი დამატებული პროდუქტი.
10. დახურე მაგიდა და აირჩიე გადახდის ტიპი.
11. შედი რეპორტებში და ნახე გაყიდვა.

## პრინტერის ჩართვა რეალურ ადგილზე

როცა პრინტერები დაყენდება, `.env` ფაილში შეცვალე:

```env
PRINTING_ENABLED=true
CASHIER_PRINTER_IP=192.168.1.50
KITCHEN_PRINTER_IP=192.168.1.51
PRINTER_PORT=9100
```

IP მისამართები უნდა იყოს იმ პრინტერების რეალური IP-ები.
