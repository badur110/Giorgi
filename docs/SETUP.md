# ლოკალური დაყენების ინსტრუქცია

## 1. საჭირო პროგრამები

- Windows ლეპტოპი
- XAMPP ან Laragon
- MySQL / MariaDB
- 2 ცალი 80mm LAN თერმული პრინტერი

## 2. ბაზის შექმნა

phpMyAdmin-ში შექმენი ბაზა:

```sql
nineteen_pleats
```

შემდეგ გაუშვი ფაილი:

```text
database/schema.sql
```

ეს შექმნის:

- 10 მაგიდას
- კატეგორიებს
- რამდენიმე სატესტო პროდუქტს
- შეკვეთების ცხრილებს
- რეპორტებისთვის საჭირო ცხრილებს

## 3. .env ფაილი

`.env.example` დააკოპირე და დაარქვი `.env`.

შეავსე:

```env
DB_DATABASE=nineteen_pleats
DB_USERNAME=root
DB_PASSWORD=

ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
CANCEL_PASSWORD=cancel123

CASHIER_PRINTER_IP=192.168.1.50
KITCHEN_PRINTER_IP=192.168.1.51
PRINTER_PORT=9100
PRINTING_ENABLED=false
```

სატესტო რეჟიმში `PRINTING_ENABLED=false` დატოვე. პრინტერების დაყენების შემდეგ შეცვალე:

```env
PRINTING_ENABLED=true
```

## 4. პრინტერები

ორივე პრინტერი უმჯობესია იყოს LAN/Ethernet.

როუტერში დაუყენე ფიქსირებული IP:

```text
სალარო: 192.168.1.50
სამზარეულო: 192.168.1.51
```

შემდეგ იგივე IP ჩაწერე `.env` ფაილში.

## 5. გახსნა მინი-აპლიკაციასავით

Desktop-ზე შექმენი shortcut:

```text
chrome.exe --app=http://localhost/nineteen-pleats/public
```

შეგიძლია დაარქვა:

```text
ცხრამეტი ნაოჭი POS
```

ამ ფორმით გაიხსნება როგორც პატარა პროგრამა, ზედმეტი ბრაუზერის ზოლის გარეშე.

## 6. საწყისი შესვლა

```text
მომხმარებელი: admin
პაროლი: admin123
გაუქმების პაროლი: cancel123
```

პაროლები აუცილებლად შეცვალე `.env` ფაილში.

## 7. მნიშვნელოვანი შენიშვნა ქართულ ტექსტზე

ზოგ თერმულ პრინტერს ქართული ასოების პირდაპირ დაბეჭდვა არ შეუძლია. თუ პრინტერმა ქართული არ დაბეჭდა, შემდეგ ეტაპზე უნდა დაემატოს ჩეკის სურათად გენერაცია და იმიჯის დაბეჭდვა.

პირველადი ვერსია აგზავნის ტექსტს ESC/POS პრინტერზე TCP/IP პორტით 9100.
